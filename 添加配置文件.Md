class ServiceTab(QWidget):
    def __init__(self, service_name: str, parent=None):
        super().__init__(parent)
        self.service_name = service_name
        self.streamer: Optional[LogStreamer] = None
        self.cfg = get_config()   # ← 新增

        self._build_ui()
        self._refresh_status()

        # 从配置读取刷新间隔
        interval = self.cfg.get("ui", "status_refresh_interval_ms", default=5000)
        self.status_timer = QTimer(self)
        self.status_timer.timeout.connect(self._refresh_status)
        self.status_timer.start(interval)

python

        act_save_list = QAction("保存当前清单", self)
        act_save_list.triggered.connect(self.save_current_list)
        toolbar.addAction(act_save_list)

    def save_current_list(self):
        """把当前打开的所有页签保存到配置"""
        count = 0
        for name, tab in self.tabs.items():
            if self.cfg.add_service(
                name,
                alias=name,
                auto_open=True,
            ):
                count += 1
        QMessageBox.information(
            self, "已保存",
            f"已保存 {count} 个服务到清单。\n配置文件: {self.cfg.config_path}"
        )

🎯 配置项说明
字段	说明
services[].name	systemd 服务名（Linux）或 Windows 服务名
services[].alias	页签显示的名称
services[].enabled	是否在启动时列入可用清单
services[].auto_open	启动时自动打开页签
services[].auto_start_monitor	打开后自动开始实时日志监控
ui.auto_scroll	日志是否自动滚动到底部
ui.log_lines	journalctl 初始显示行数
ui.status_refresh_interval_ms	状态刷新间隔（毫秒）
ui.window_width/height	启动窗口尺寸
backend.type	auto / systemd / windows
advanced.max_log_buffer_lines	日志缓冲区最大行数（超过自动截断）
💡 使用流程

    第一次运行：自动生成默认配置到 ~/.config/service-monitor/config.json。

    手动编辑：直接修改该文件，添加你想监控的服务名。

    从界面保存：打开若干服务的页签后，点击工具栏“保存当前清单”，把它们写入配置。

    下次启动：所有 auto_open: true 的服务会自动打开页签。

🔧 可选：添加“打开配置文件”按钮

在工具栏加一个按钮，方便直接编辑：
python

        act_open_cfg = QAction("打开配置文件", self)
        act_open_cfg.triggered.connect(self.open_config_file)
        toolbar.addAction(act_open_cfg)

    def open_config_file(self):
        """用系统默认编辑器打开配置文件"""
        path = self.cfg.config_path
        if not path.exists():
            self.cfg.save()
        if IS_WINDOWS:
            os.startfile(str(path))
        else:
            subprocess.Popen(["xdg-open", str(path)])

这样你就能在 GUI 里一键打开配置文件，编辑完保存后重启应用即可生效。如果你希望修改配置后不重启就热加载，我可以再补充一个 QFileSystemWatcher 监听文件变化的实现。
